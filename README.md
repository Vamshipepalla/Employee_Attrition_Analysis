# 📊 Employee Attrition — Exploring Workforce Trends

> Understanding employee data through Python, data analysis, and visualization.

## About the Project

This project focuses on exploring employee data to understand workforce characteristics and trends over time. Using Python and Exploratory Data Analysis (EDA), I cleaned and transformed the dataset, analyzed employee demographics and experience, and explored hiring and termination patterns.

## 🎯 Project Objectives

- Clean and prepare employee data for analysis.
- Explore employee age, experience, departments, and job roles.
- Analyze hiring and termination trends across years.
- Identify patterns and outliers using data visualization.
- Present observations in a clear and meaningful way.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Python | Data analysis |
| Pandas | Data cleaning and manipulation |
| NumPy | Numerical operations |
| Matplotlib | Data visualization |
| Seaborn | Statistical visualization |
| Jupyter Notebook | Interactive analysis |

## 🔍 Analysis Highlights

- Employee demographics and experience
- Department and job-role distribution
- Hiring and termination trends over time
- Relationships between age and experience
- Data distributions and outlier exploration

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Vamshipepalla/employee-attrition-analysis.git
```

**2. Open the project folder**

```bash
cd employee-attrition-analysis
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `Attrition.ipynb` and run the cells. Keep `Attrition_dataset.csv` in the same folder as the notebook.
